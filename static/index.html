ส่งออกข้อมูล (Export Data)

เลือกรูปแบบไฟล์ที่ต้องการดาวน์โหลดเพื่อนำไปเปิดใช้งานบนเครื่องอื่น หรือเก็บสำรองข้อมูลไว้:

ฐานข้อมูลฉบับเต็ม (.db) แนะนำสำหรับการย้ายเครื่อง

บันทึกทุกตาราง ประวัติงานซ่อม ลูกค้า สต็อก การเงิน ทั้งหมด 100% สามารถนำไป Restore เข้าเครื่องอื่นได้ทันที

ไฟล์ข้อมูล JSON (.json) Universal JSON

ส่งออกข้อมูลแบบข้อความ JSON สำหรับดูข้อมูล วิเคราะห์ใน Excel หรือเลือกผสานข้อมูล (Merge) ในเครื่องอื่น
