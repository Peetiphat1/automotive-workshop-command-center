==============================================================================
   คู่มือการเปิดใช้งานระบบ AUTOMOTIVE WORKSHOP COMMAND CENTER
   (One-Click Auto Setup & Run Guide)
==============================================================================

🎉 ยินดีต้อนรับ! ระบบนี้ถูกออกแบบให้ติดตั้งสภาพแวดล้อม (Environment) 
และเปิดใช้งานได้อัตโนมัติ เพียงแค่ดับเบิ้ลคลิกเดียว ไม่ต้องพิมพ์คำสั่งเอง!

------------------------------------------------------------------------------
⚡ ขั้นตอนการเปิดใช้งานบน Windows (Real PC):
------------------------------------------------------------------------------
1. แตกไฟล์ ZIP (Extract All) ออกมาไว้ที่โฟลเดอร์ใดก็ได้ตามต้องการ (เช่น Desktop)
2. ดับเบิ้ลคลิกที่ไฟล์:
       👉 START.bat   (หรือ run.bat)
3. ระบบจะทำงานอัตโนมัติทันที:
   - ตรวจหา Python ในเครื่อง
   - สร้าง Virtual Environment (.venv) ให้อัตโนมัติ
   - ติดตั้ง Library ที่จำเป็นทั้งหมดจาก requirements.txt ให้อัตโนมัติ
   - ตั้งค่าคอนฟิกสภาพแวดล้อม (.env) ให้อัตโนมัติ
   - เปิดหน้าต่าง Web Browser เข้าสู่ระบบ Dashboard ให้โดยอัตโนมัติ!

------------------------------------------------------------------------------
⚠️ สิ่งที่ต้องมีในเครื่องคอมพิวเตอร์ก่อนเปิดใช้งาน (ทำครั้งเดียว):
------------------------------------------------------------------------------
- คอมพิวเตอร์ต้องมี Python 3.10 ขึ้นไป
  หากยังไม่มี สามารถดาวน์โหลดได้ฟรีที่: https://www.python.org/downloads/
  
  *** ข้อสำคัญที่สุดตอนติดตั้ง Python ***:
  ในหน้าต่างแรกของการติดตั้ง ให้ติ๊กเครื่องหมายถูกที่ช่อง:
  [X] "Add python.exe to PATH"  (อยู่ด้านล่างสุดของหน้าต่างติดตั้ง)
  แล้วจึงกด "Install Now"

------------------------------------------------------------------------------
🌐 หน้าจอการใช้งานหลัก (เมื่อระบบทำงานแล้ว):
------------------------------------------------------------------------------
- Dashboard ควบคุมอู่ซ่อมรถ:  http://localhost:8000/dashboard
- ระบบจัดการสต็อกและอะไหล่:   http://localhost:8000/stock
- สแกนป้ายทะเบียน / OCR:      http://localhost:8000/scan
- ลูกค้าติดตามสถานะงานซ่อม:    http://localhost:8000/track
- เอกสารทดสอบระบบ API:        http://localhost:8000/docs

------------------------------------------------------------------------------
🛑 วิธีปิดโปรแกรม:
------------------------------------------------------------------------------
- ปิดหน้าต่างสีดำ (Command Prompt) หรือกดปุ่ม Ctrl + C ในหน้าต่างนั้น

------------------------------------------------------------------------------
🍎 สำหรับผู้ใช้งานบน macOS / Linux:
------------------------------------------------------------------------------
- เปิด Terminal แล้วสั่ง: ./START_MAC_LINUX.sh (หรือ bash run.sh)
- ระบบจะติดตั้งและเปิดเว็บให้โดยอัตโนมัติเช่นเดียวกัน
==============================================================================
